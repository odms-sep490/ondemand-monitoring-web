# Office character assets

The animated staff models in this directory are from Quaternius' Ultimate Animated Character Pack.

- Source: https://quaternius.com/packs/ultimatedanimatedcharacter
- License: Quaternius Asset License (the pack page identifies this pack as CC0): https://quaternius.com/license.html
- Included files: `casual-male.fbx`, `casual-female.fbx`

These models are used only as illustrative ambient characters in the Manager office view. They are not identity photos or claims about a staff member. Mission assignments and work status continue to come from the application APIs; scene animation never changes backend data.
